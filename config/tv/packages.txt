#
# Background: with these 21 disabled as well (126 in total), YouTube's hardware AV1 decoder
# produced corrupted frames at a scene cut (GW5bAVgULEA at 7:49, old scene leaking into the
# new one); software decoders decoded the same frame cleanly, and with these enabled the TV
# did too. Never pinned to one package. (Bravias also have a known decoder bug on resolution
# switches with no debloat at all: github.com/google/ExoPlayer/issues/7248.)
#
#   Reported to break things when disabled:
#     com.google.android.tungsten.setupwraith   Sony volume control and sound settings (UAD)
#     com.android.certinstaller                 Wi-Fi (UAD: unsafe)
#     com.android.localtransport                backup transport (UAD: unsafe)
#     com.android.statementservice              app-link verification (UAD: unsafe); crashes at boot anyway (known Android 12 issue)
#     com.android.dynsystem                     dynamic system updates (UAD: unsafe/expert)
#     com.android.settings.intelligence         Settings crashes on search (UAD)
#     com.sony.dtv.ecodashboard                 some Settings options (UAD)
